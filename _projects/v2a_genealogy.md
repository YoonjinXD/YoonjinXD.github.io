V2A Genealogy is a single, filterable page that lists the representative video-to-audio generation systems, evaluation metrics and datasets from 2016 to 2026. Each entry is tagged along several axes, such as how the conditioning signal is represented, how it is injected into the model, the backbone and the kind of control it offers.

Filtering dims the entries that don't match instead of hiding them, so you can see how much of the field a given combination covers. The filtered view is stored in the URL, so it can be shared as a link.
